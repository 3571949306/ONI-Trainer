# 缺氧修改器

一款适用于 **Steam 版《缺氧 / Oxygen Not Included》** 的单机辅助工具。双击即可运行，无需在游戏内安装任何附加内容，也无需修改游戏文件。

> **测试版**：当前版本加入了批量扫描、复制人编辑、自动更新等新功能，其中部分功能**尚未经过完整实测**，可能存在不稳定或细节问题。建议在使用前备份存档；遇到问题可回退到上一个正式版，并通过仓库 Issue 反馈。

## 下载

- 推荐：在仓库页面右侧的 **Releases** 中下载最新版本，测试版会标注为 `Pre-release`。
- 也可以直接使用仓库中 `dist` 文件夹里的 `ONI-Trainer.exe`。

下载后得到一个独立的可执行文件，不需要解压出其他文件。支持 Windows 10 / 11 64 位系统，可放到任意目录使用，**支持中文路径**，无需额外安装运行库。

## 快速开始

1. 双击运行 `ONI-Trainer.exe`（可先开修改器，也可以进入游戏存档后再开）。
2. 启动 Steam 并进入《缺氧》存档。
3. 修改器会自动检测状态，窗口顶部的状态提示依次为：
   - `● 等待启动游戏…`：尚未检测到游戏。
   - `● 游戏已运行，等待进入存档…`：游戏已启动，请载入殖民地存档。
   - `● 已连接存档 · 功能就绪`：全部功能可用。
4. 点击窗口中的功能按钮，或使用热键。每次操作都会在任务日志中显示结果。
5. 关闭修改器时，已开启的倍速、压力与士气相关设置、建造挖掘提速及生存状态锁会自动恢复。

> 如果游戏是以管理员身份运行的，请同样右键修改器，选择「以管理员身份运行」。
> 默认在首次修改前会自动把当前存档备份为 `.bak` 文件。

| 单格刷资源 | F8（可改） | 只修改鼠标指向的那一格；固体格会被拒绝，气体、液体与真空格按设定质量与温度写入；提供氧气/水/石油/超冷剂/液氢快捷选择 |
| 游戏倍速 | — | 支持 1–100 倍速，附带「恢复 1x」按钮，关闭修改器时自动恢复 |
| 地图视野 & 间歇泉分析 | — | 揭开已探索星球的迷雾，让火山、间歇泉与庄严科技遗迹立即显影；「分析全部间歇泉」可跳过野外分析作业，直接查看全部喷孔参数 |
| 压力上限 | — | 持续把压力限制在设定值以下，设为 0% 即无压力，可随时关闭 |

| 高级功能面板（**测试**） | — | 在「设置」开启后显示：极速建造/挖掘/机械/移速、5 项生存状态持续锁、鼠标格工具（升温/降温/抽真空），以及 **12 维工作属性（含驾驶）与特质增删编辑器（附游戏内说明）** |

## 开局种子与星球特质筛选

无需先启动游戏或进入存档即可使用。

1. 打开修改器，点击顶部的「**开局种子筛选**」。
2. 工具会自动检测本机游戏目录与已安装的扩展内容；在游戏停留在主菜单时，可点击「**读取游戏设置**」同步故事特质与混搭后缀。
3. 选择「小行星风格」与「星群」，例如 `经典 → 汪洋星星群 [V-AQU-C]`；如需保留坐标后缀，也可直接贴入「保留坐标后缀」框。
4. 在左侧选择要定制的小行星（初始 / 临近 / 遥远），在右侧勾选希望刷出的特质，也可以设置排除条件。
5. 点击「**开始后台筛选**」。命中结果会自动存入会话历史；点击「**★ 收藏**」可持久保存完整种子信息及已生成的地图快照，通过「历史/收藏」可离线回载预览并编辑备注。
6. 点击「**复制完整坐标**」，进入游戏的「选择一个目的地」界面粘贴即可验证。

### 地图预览与星群总览（**测试**）

- 在候选种子列表中选择一个种子，点击「**预览地图**」，在主菜单或存档内均可生成高清交互式地貌图，并支持**导出高清 PNG**。
- 可查看间歇泉的真实均产、温度、活跃/休眠周期与 S-A-B-C 评级，便于判断种子是否合适。
- 点击「**整星群总览**」可批量扫描全星群中的每一颗小行星，双击列表项即可跳转地图预览。
- 预览支持纯元素色、温度热力图与分类过滤。
- 高级模式（设置中开启）提供 `@category` 等通配条件、`≥`/`≤`、`距起点≤`、`均产≥` 等二次过滤。

## 设置与更新

- **快捷键**：支持全局快捷键自定义，含禁用/恢复 F5–F10。
- **提示与备份**：可开关游戏内浮动提示；默认首次修改前自动备份存档。
- **自动更新（测试）**：设置中可开启自动检查更新（默认关闭），也支持手动检查与一键下载更新；「关于」区显示当前版本与开源仓库地址。
- **日志**：可一键打开日志目录，便于排查问题。
- 高级模式的配置会保存在本地，下次启动仍然生效。

## 常见问题

**状态一直停在「等待启动游戏」怎么办？**
请确认游戏是通过 Steam 启动的，并且 Steam 客户端正在运行。直接运行游戏安装目录中的程序可能无法正常检测。

**提示权限不足或无法访问游戏？**
请右键修改器，选择「以管理员身份运行」，并确保游戏与修改器使用相同权限级别。

**安全软件提示风险怎么办？**
本工具需要连接到正在运行的游戏才能实现修改功能，部分安全软件可能因此提示。确认文件来源可靠后，可选择信任并允许运行；本工具不会修改游戏文件、注册表或系统设置。

**地图预览/批量扫描无法使用？**
请先返回游戏「主菜单」，再选择候选种子或启动星群总览。若游戏未启动或路径未被识别，请检查设置中的游戏目录。

**测试版出问题怎么办？**
可到 Releases 页面下载上一版正式版覆盖使用，并在仓库 Issue 中描述问题与复现步骤。

**支持哪些游戏版本？**
适用于当前 Steam 版本的《缺氧》。游戏大版本更新后，部分功能可能需要跟随更新。

**会影响成就或存档吗？**
本工具不改变游戏安装文件，也不在游戏内安装任何内容，成就判定不受影响。建议单机自用，不要在联机环境或分享存档时使用。
